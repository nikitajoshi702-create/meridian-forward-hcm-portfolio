# Meridian Forward HCM AS2 — Problem & Output Portfolio

This Streamlit portfolio is deliberately limited to two sections:
- **Problem:** the business challenge, capacity evidence and specialist capability gaps.
- **Output:** the proposed HR solution, decision metrics and downside decision gate.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and `README.md` to the repository root (upload the files, not the ZIP).
3. Open Streamlit Community Cloud and create an app from the repository.
4. Choose branch `main` and main file `app.py`, then deploy.
